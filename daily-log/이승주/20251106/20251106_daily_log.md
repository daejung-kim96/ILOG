### 📝 회고

- 도커의 ports는 외부 포트 즉 호스트와의 연결을 위해 설정된다. 기본적인 expose 내부 포트는 이미지 생성 시점에 결정된다.
  - expose는 도커 내부 네트워크를 공유하는 어플리케이션에게 열어주는 것
- 카프카의 경우 listen 설정을 통해 포트 설정을 구현할 수 있다.
  - 카프카는 브로커,컨트롤러 설정을 통해 kafka kRaft를 활용하여 컨트롤러 역할을 수행할 브로커를 정할 수 있다. 컨트롤러로 선출되면 컨트롤러 포트를 통해 토픽 리더를 설정하고 각 브로커의 상태를 관리한다.
  - 리더로 선출된 브로커는 토픽의 주요 기능을 수행하며 부하 브로커에게 데이터를 복사한다.
  - 커넥터는 브로커에 랜덤하게 접근하여 각 파티션에 대한 리더 정보를 받아 아웃박스 이벤트 발행을 수행한다.
